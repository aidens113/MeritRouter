## Trigger and changes

The real Facebook pilot could not launch its delegated supervisor: every endpoint lacked
manually entered quality evidence. The initiating supervisor incorrectly substituted direct
workers; the user rejected that workflow and explicitly authorized root framework fixes.
Further observed problems were failed tasks after three unavailable models and serial or
malformed batch operations.

- Default supervisor policy is now best_available, with honest null/unverified quality when
  measured evidence is absent. Explicit frontier_or_qualified_supervisor remains strict.
  Verified evidence ranks first; ordinary qualification/capacity ranks eligible fallbacks.
  Unverified size floors, paid/access/tool/modality restrictions and dispatch checks remain.
- The example and generated default preset no longer persist an empty mandatory evidence gate.
  All four presets are regenerated by the existing script.
- Impossible supervisor submissions return a typed actionable error atomically, with no doomed
  task/batch rows. Idempotent replays remain readable.
- Definite free account/model refusals no longer consume the transient fallback allowance.
  One finite candidate pass, physical request accounting, paid caps and cancellation remain.
  Model-not-found and not-in-plan caches are per credential/model, with existing expiry/reset.
- Native and task-MCP schemas expose concrete nested fields and required edit actions, retain
  legacy file strings, and permit operation-specific paging bounds. Nested dialect tags are
  omitted. Safe same-turn reads coalesce in groups of four invocations; each read_files has
  four file workers. Commands/edits remain barriers, and pending approval halts grouped checks.
